# Bloodborne Native Port Field Guide

A static, source-cited report explaining Bloodborne's native-port architecture and setup paths for Windows, Linux/Steam Deck, and Apple-silicon macOS, with a broader decomp/recomp primer.

The finished static site is published directly from this repository's root through GitHub Pages. It deliberately contains no copyrighted game data, PKG links, keys, or firmware.

## Local preview

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
